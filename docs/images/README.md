## Prompts

Use these in Microsoft Designer or another image tool. Do not paste real alerts, hostnames, or customer data into the prompt.

**dashboard.png**

Enterprise cybersecurity product screenshot, dark theme, security operations center, wide monitor, alert queue with severity chips, MITRE technique IDs, teal accents, no readable company names, no real logos, clean sans serif, modern SaaS, high end, not cartoon.

**investigation.png**

Dark enterprise security application, incident investigation page, left column narrative, right column audit trail of agent steps, citation chips, teal on near-black, SOC analyst view, no readable personal data.

**copilot-chat.png**

Dark chat-style security copilot, analyst pasted an alert, response shows technique, citations, and containment steps, Microsoft Security Copilot mood without copying the logo, teal highlights, crisp UI.

**agents.png**

Architecture poster, five connected nodes labeled guardrails, detection, threat intel, investigation, remediation, dark background, thin teal lines, enterprise diagram, plenty of margin.

**architecture.png**

System diagram poster, user to Streamlit to FastAPI to investigation graph to knowledge base to report, dark SOC aesthetic, teal, no vendor logos.

**governance.png**

Dark security control panel, prompt injection blocked, redacted email and secret tokens, shield motif, teal and amber status, enterprise, no real secrets.

**rag-pipeline.png**

Left to right pipeline, documents, index, retrieval, cited response, dark background, teal nodes, technical poster, no logos.

Do not present generated art as a photograph of a deployed customer environment.

# Roadmap

The reference build is the slice an interviewer can run. These are the next slices, in order.

1. More techniques, still with a recall test that must pass before merge.
2. A Chroma index built from the same markdown, with a comparison against TF-IDF on paraphrased questions.
3. A Gemini narrative path that is forbidden from mentioning any source that was not retrieved.
4. Authentication and a per-tenant knowledge filter.
5. An analyst accept or reject button that writes a labeled file for later review.
6. LangGraph as the runner, with the current functions left as the nodes.

No item above is claimed as finished.
